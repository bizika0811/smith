# WordSprout

面向 1-6 年级小学生的英语单词记忆 Web/PWA 项目，核心方向是：

- 教材单元级同步
- 科学记忆调度
- 多模态学习流
- 学完即走的反成瘾体验
- 家长基础可见性

当前仓库阶段以文档设计和开发步骤拆分为主，尚未进入完整代码实现阶段。

---

## 1. 项目简介

WordSprout（词芽）是一个面向小学生的英语单词学习工具，目标不是做大而全的英语学习平台，而是围绕“单词记忆”这个核心任务，提供一条完整、简单、适龄的学习闭环：

```text
选教材单元 -> 学新词 -> 做复习 -> 达到上限 -> 完成页退出 -> 家长查看结果
```

与常见成人背词工具相比，WordSprout 更强调：

1. 与小学教材同步
2. 面向儿童的低认知负担
3. 多通道学习而不是单纯看释义
4. 限制时长和任务量，避免无限刷题

## 3. 核心目标

第一版目标如下：

1. 支持至少 1 套教材的单元级单词学习
2. 支持五步学习流：看、听、说、写、用
3. 支持 SRS 复习任务调度
4. 支持每日任务上限
5. 支持完成页
6. 支持家长基础查看页

第一版明确不做：

1. 原生 APP
2. 教师完整后台
3. 班级实时 PK
4. 商业支付系统
5. 复杂会员体系

## 8. MVP 验收标准

一个合格的第一版至少要满足：

1. 能启动前后端
2. 能选择教材和单元
3. 能完整走通至少一个单词的五步学习流
4. 能生成复习任务
5. 能限制每日学习量
6. 能展示完成页
7. 能让家长查看基础学习记录

建议最终演示流程为：

```text
首页 -> 选单元 -> 学习 1-2 个单词 -> 进入复习 -> 达到上限 -> 完成页 -> 查看家长页
```

## 10. 与研究文档的关系

WordSprout 不是凭空设计出来的，它直接建立在前期竞品与理论研究之上。

研究文档已经明确：

1. 成人向背词产品通常不适合直接给小学生当主力工具
2. 小学生场景下，教材同步、低龄友好、防沉迷、家长可见性比单纯“功能多”更重要
3. WordSprout 的机会点在于同时兼顾教材同步、科学记忆和轻量陪伴

因此，本项目的设计并不是“拍脑袋功能堆砌”，而是研究驱动的产品方案。
