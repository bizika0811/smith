# Flashcard Demo

独立的 Flashcard 学习卡演示应用，基于 `Flashcard开发功能_优化版.md` 的核心需求实现。

当前版本已包含：

- 卡片正反面展示
- Again / Hard / Good / Easy 队列调度
- 键盘快捷键
- 浏览器语音朗读
- 自定义单词导入与自动分组
- 本地进度保存
- 导出为单文件 HTML

本地运行：

```bash
cd flashcard-demo
node server.js
```

默认地址：

```text
http://127.0.0.1:4180
```

如果只是预览，也可以直接用浏览器打开 `index.html`。
